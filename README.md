# Prumysl Landing Pages

This workspace contains the Arabic and French landing pages for Prumysl solar products.

## Structure

- `index.html` — Arabic landing page
- `index-fr.html` — French landing page
- `assets/` — shared assets, including the logo
- `css/` — shared styling tokens for future cleanup and reuse
- `js/` — shared JavaScript for page behaviors

## Open locally

Open `index.html` or `index-fr.html` in a browser.

## Notes

The project is a static HTML landing page designed for desktop and mobile and keeps the same product content, B2B positioning, and conversion flow across both language versions.
